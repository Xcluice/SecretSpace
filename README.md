# Notes (SecretSpace)

A notes app that hides a second Android space. Type the secret title (default `.space`) as a note title to open it. Change it inside the hidden space.

- Second space = Android work profile with its own apps, data and Play Store.
- Android 15+: also links to the system Private Space settings.
- Release APK is built by GitHub Actions on every push to `main` and published as a release.
